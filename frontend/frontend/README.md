# Workshop Parts Desk - Frontend

React + Vite + Tailwind dashboard. It talks only to the FastAPI backend; the Groq key stays in `backend/.env`.

```powershell
npm install
npm run dev
```

Open http://localhost:5173. The backend must be running at http://127.0.0.1:8000
(change with `VITE_API_URL` in `frontend/.env`).
